YamlAnchor

A local-first tool that scans a repo, generates its GitHub Actions workflow, and runs that pipeline in Docker before you push, so CI failures show up on your machine first.

  • AST-based scan detects languages, build tools and test runners across Go, TypeScript and Python projects.
  • Tailored workflow generation that reflects what is actually in the repo, not a generic template.
  • Local simulation runs each step in isolated Docker containers and streams logs to the UI over NDJSON.
  • Secret scanner and self-healing flags exposed credentials, pinpoints the failing step and suggests a fix.
