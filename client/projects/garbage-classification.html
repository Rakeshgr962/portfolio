01 / Overview

A dual-tier sustainability project combining a transfer learning computer vision model for automated physical waste segregation with AI-EcoSort, an accessible web assistant developed for the 1M1B IBM SkillsBuild AI for Sustainability program.

02 / The Problem

Municipal waste contamination costs millions annually. Physical recycling centers need rapid image sorting across waste types, while households need clear, honest guidance on proper disposal categories without misleading AI claims.

03 / My Solution & Architecture

Computer Vision: EfficientNetB0 backbone pre-trained on ImageNet, fine-tuned with 124x124 input resolution, Global Average Pooling, Dropout (0.2), and early stopping across 6 waste categories (cardboard, glass, metal, paper, plastic, trash). Web Assistant: React 19 + TypeScript with a deterministic rule-based knowledge engine, confidence indicators, and Vitest test coverage.

Key Engineering Decisions & Trade-Offs

EfficientNetB0 Pre-trained Backbone over Scratch Training

Compound scaling in EfficientNet achieves state-of-the-art feature representation while maintaining low parameter counts, making it ideal for rapid inference on constrained hardware.

Global Average Pooling & Dropout (0.2) Regularization

Replaced dense classification blocks with global average pooling to prevent overfitting on specific lighting and background variations.

Honest Responsible AI Architectural Separation

Strictly separated client-side image preview components from text classification rules in AI-EcoSort to eliminate false claims of on-device vision.

  • Transfer learning pipeline with data augmentation and early stopping.

06 / Results & Verified Findings

  • 89.24% reproducible test accuracy on public benchmark dataset.
  • Zero false-claims design: Clear user disclosure on rule-based text logic vs experimental LLM integration.
  • Dual-stack portfolio proof: Demonstrates deep learning transfer learning alongside clean TypeScript client engineering.

07 / What I Learned & Direct Contributions

Key engineering responsibilities and lessons gained during this project:

  • Trained and evaluated EfficientNetB0 transfer learning model achieving 89.24% test accuracy on public benchmark data.
  • Built and deployed interactive Gradio web demonstration for real-time image inference.
  • Engineered AI-EcoSort interface with strict Responsible AI guardrails (explicitly marking text classification vs image upload preview).
  • Implemented automated test suite in Vitest verifying rule classifications and uncertainty thresholds.

08 / Future Improvements

AI-EcoSort image upload currently functions as a preview component; direct client-side on-device TF.js inference is the target architectural milestone.
