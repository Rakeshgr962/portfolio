01 / Overview

A sustainable waste classification web assistant created for the 1M1B IBM SkillsBuild AI for Sustainability program. Combines deterministic rule-based classification, confidence scoring, and responsible user disclosures.

02 / The Problem

Many AI applications exaggerate capabilities or fabricate high confidence scores on ambiguous inputs. Furthermore, users need clear, actionable guidance on whether an item is recyclable, compostable, or hazardous without depending on heavy cloud GPUs.

03 / My Solution & Architecture

Built using React 19 + TypeScript with Vite. Implements a multi-stage deterministic classification pipeline that validates keywords against waste category databases, provides disposal instructions, and outputs transparent confidence scores with fallback uncertainty warnings.

Key Engineering Decisions & Trade-Offs

Deterministic Rule Engine over Hallucinating Prompt Wrapper

Municipal recycling standards require strict predictability. A deterministic rule base guarantees accurate disposal instructions without random generative variance.

Transparent Uncertainty Disclosures

If an item contains ambiguous or multi-material components (e.g., plastic-lined paper coffee cups), the engine explicitly flags an uncertainty warning instead of guessing.

Comprehensive Vitest Test Suite

Codified test cases for dozens of common household items, ensuring that refactoring never breaks classification accuracy.

06 / Results & Verified Findings

  • Deployed live on Netlify with 100% client-side execution and zero cold-start latency.
  • Zero false claims: Clear user disclosure on rule-based text logic vs experimental vision previews.
  • Recognized under the 1M1B IBM SkillsBuild AI for Sustainability initiative.

07 / What I Learned & Direct Contributions

Key engineering responsibilities and lessons gained during this project:

  • Built high-performance, accessible UI with carbon-conscious dark styling and responsive layouts.
  • Engineered deterministic classification engine with explicit uncertainty handling for ambiguous inputs.
  • Separated text classification logic from client-side image preview components (zero false computer vision claims).
  • Wrote comprehensive unit test suite in Vitest verifying rule classifications and confidence thresholds.

08 / Future Improvements

Image upload currently functions as an accessible visual preview; on-device TensorFlow.js client inference is planned for future offline computer vision sorting.
