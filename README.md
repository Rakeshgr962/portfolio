# Rakesh G R Portfolio Website 🌐

[![License](https://img.shields.io/github/license/Rakeshgr962/rakeshgr?style=flat-square)](LICENSE)
[![Vercel Deployment](https://img.shields.io/badge/deploy-vercel-black.svg?style=flat-square)](https://vercel.com)

This repository contains the source code for my personal developer portfolio website. The site serves as a central hub showcasing my expertise in data science, software engineering, and IoT projects.

---

## 🛠️ Architecture & Tech Stack
- **Frontend Client**: Semantic HTML5, Custom CSS3 variables (Dark-mode responsive design), and Vanilla JavaScript (interactive animations, project details search).
- **Backend Handler**: Node.js microserver deployed on Vercel handling form submissions and mail notifications.

---

## 🚀 Getting Started

### Local Setup
1. **Clone the repository**:
   ```bash
   git clone https://github.com/Rakeshgr962/rakeshgr.git
   cd rakeshgr
   ```

2. **Run Backend Server**:
   ```bash
   cd server
   npm install
   npm start
   ```

3. **Run Frontend Client**:
   Open `client/index.html` in your browser.
